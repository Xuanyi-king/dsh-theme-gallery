# DSH 主题库

**简体中文（默认）** | [English](README.en.md)

一个插件，十款主题。安装后在 DeepSeek Harness 的「设置 → 主题」中随时切换，也可以选「跟随 DSH」恢复默认；选中的主题在关闭并重新打开 DSH 后仍会保留。

主题设置提供「背景深淡」「侧栏遮罩」「背景模糊」「文字对比」四个滑条。深淡调节聊天场景的底色，侧栏遮罩独立调节左侧壁纸上方的底色，默认 40%，十款主题共用；设置页的半透明底色无需单独调节。拖动即可预览，数值保存在当前设备，重启后仍然有效；选择 DSH 内置主题时这些调节不会改变内置外观。模型生成回复期间，每款主题在原生状态栏显示自己的文字、用时与小型动态标记，兼容 DSH 0.2 的独立运行状态栏；启用系统的减少动态效果后，标记保持静止。

v0.3.18 修复 DSH 0.2.0-rc.2 的原生鲸鱼动效与主题标记叠加，并修复启动时旧配色覆盖已保存主题、导致文字变黑的问题。回复状态改为紧凑的单行标记，主题图标仅作轻微呼吸或浮动，文字与计时保持清晰。

v0.3.19 修复阿良、晴空守望、少年悟空被后端拒绝保存、重启后恢复成旧主题的问题。十款主题统一隐藏首页“预览版”标记，沿用相同的原生布局与功能控件；新三款接入各自配色、图标与文案的启动开场。

主题图像使用新制作的视觉素材，涉及《龙珠》等作品角色的主题为非官方同人设计，不代表角色形象或相关知识产权为原创，也不代表获得官方授权。每款主题都有专属配色和场景图；背景覆盖 DSH 的实际对话区域，文字区域保留渐变遮罩以便阅读。运行提示使用 DSH 原生文字，避免装饰动画干扰阅读。

## 安装

在 DSH 桌面应用中打开「插件 → 添加插件」，在输入框粘贴下面的仓库地址，点击「安装」：

```text
https://github.com/Xuanyi-king/dsh-theme-gallery
```

通过 Web profile 的命令行安装时，也只需一条命令：

```bash
dsh plugin --profile web add https://github.com/Xuanyi-king/dsh-theme-gallery
```

安装后打开「设置 → 主题」，点击喜欢的主题卡片即可切换，不需要为每款主题分别安装插件。
升级后关闭、重开一次 DSH，加载新版插件；已保存的主题会自动恢复。已安装的旧版单款主题插件需要移除，避免同时覆盖界面样式。

## 切换、恢复与保存

「设置 → 主题」包含十款主题和「跟随 DSH」「DSH 明亮」「DSH 深色」三个内置选项。选择「跟随 DSH」会清除主题库的覆盖设置，恢复 DSH 默认外观；随时可以再次选择主题。

选择会写入 DSH 本机配置目录中的 `dsh-theme-gallery/selection.json`；页面同时保存本地副本，供宿主未提供配置接口时恢复。重启 DSH 后会重新读取选择。如果此前安装过旧版单款主题插件，请先移除那些旧插件，避免旧版装饰同时运行。

## 启动动画

选中「山河剑意」并保存后，重新打开或刷新 DSH 页面，会展示约 4 秒的水墨开场：现有壁纸缓慢推进，墨线展开，朱砂印章与主题文案依次出现。它是图片与代码动画，不需要视频或联网素材。

「阿良 · 雨夜行」「晴空守望」「少年悟空 · 筋斗云之旅」也支持约 4 秒的启动开场，复用相同流程与布局，分别展示各自的场景、剑光／朝阳／筋斗云图标、配色和主题文案。升级后请重新选择一次之前未能保存的新主题。

点右上角「跳过」或按 Esc 可以立即关闭。动画只在页面启动时播放一次，切换主题和打开新对话不会重播；其余六款主题暂不播放。系统启用「减少动态效果」时，不显示开场。

播放前会等待已保存的主题恢复。如果宿主配置请求超过 1.5 秒仍未完成，则按本地已保存的主题决定是否播放；稍后收到配置也不会再次弹出。启动期间手动选择主题，也不会触发延迟播放。

## 开发与验证

```bash
npm run build
npm test
npm run pack:gallery
```

仓库根目录是统一安装包。各款主题的原始资源与测试保留在 `themes/<name>/`，便于继续迭代；启动动画只接入统一安装包，不改动单款主题包。

可选浏览器验证使用真实 React 和已构建的 `lib/client.js`，覆盖四款开场的桌面、手机、跳过、Esc、自动关闭、减少动态效果和主题恢复，以及新三款首页的标记、标题布局与输入控件可用性。先在仓库外安装 `playwright`、`react@18` 和 `react-dom@18`，并安装 Playwright Chromium，再运行：

```bash
DSH_INTRO_BROWSER_TOOLS=/你的浏览器工具目录 node scripts/verify-startup-browser.mjs
```

也可设置 `DSH_INTRO_BROWSER_EXECUTABLE` 指向已安装的 Chromium 系浏览器可执行文件，例如 Windows 的 Microsoft Edge，无需另行下载 Playwright Chromium。

默认截图和离线预览文件 `shanhe-preview.html` 保存到 `/tmp/dsh-shanhe-intro-preview/`。用浏览器打开该 HTML 文件即可查看样板，动画结束后可以点击「重播山河开场」。浏览器测试使用模拟 DSH 服务，安装到实际 DSH 后仍需检查宿主内效果。
